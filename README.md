# Observer's Moon Atlas (OMA)

A web-based interactive Moon atlas: a 3D lunar globe relit for any date and
time, with accurate libration and terminator, a searchable feature database,
and tools for visual observers and astro-imagers.

**Project:** THG Media
**Status:** Planning. Working name; stack, domain and repo not yet decided.
**Started:** 2026-10-22

Built on the THG Media project skeleton (`thg-media/skel-hugo/`). Nothing here
is built yet.
